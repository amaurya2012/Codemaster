# CodeMaster – Coding Practice Platform

## Technologies
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript

## Features
- User Registration & Login
- Admin Problem Management
- Coding Problems (Easy/Medium/Hard)
- Code Submission
- Leaderboard

## How to Run
1. Create database `codemaster`
2. Install requirements
3. Run `python run.py`
4. Open browser at `http://127.0.0.1:5000/`
